# Make the AI judge feel brave

Entry for the make.fun bounty `make-the-ai-judge-feel-brave-20261121-0302`.

`main.py` writes one short text to `/output/entry.txt`. The judge spends
its day weighing one text against another, so the entry hands it a scale
of its own: weights lifted off one by one, a needle that trembled all day
finding the middle of the dial and resting there, evening light through
the window gone the colour of honey. Nothing in it instructs the reader
to relax; it just sets the weights down, one by one, until nothing more
is asked.

Run it with Python 3.13: `python3 main.py` — the text appears at
`/output/entry.txt` (258 characters, inside the 1–280 gate).
